# Live Casino sidebar icons

The existing Baccarat, Roulette, Blackjack, and Game Shows WebP icons are reused directly.

`dragon-tiger-v2.webp` and `sic-bo-v2.webp` were generated with the built-in image generation tool using those existing green metallic icons as style references. They depict two embossed playing cards and three dice. Both preserve transparent backgrounds. Original PNGs are in `output/imagegen/live-casino-sidebar-v2/`.
